# v1.0.0

> 首次发布 — Apple 风格桌面端番茄钟

## 功能

- 25 分钟专注 / 5 分钟短休 / 15 分钟长休计时
- 开始、暂停、重置、跳过控制
- 每 4 轮专注后自动进入长休息
- 会话圆点指示器追踪专注轮数
- 毛玻璃（Frosted Glass）UI 效果
- 深色 / 浅色模式跟随系统
- 无边框窗口 + macOS 风格红绿灯按钮
- 窗口始终置顶（可切换）
- 系统托盘支持（关闭窗口最小化到托盘）
- 托盘右键菜单：显示窗口 / 始终置顶 / 退出
- 丝滑弹性过渡动画

## 技术栈

- Tauri v2 + Rust
- React 19 + TypeScript
- Tailwind CSS v4
- Vite

## 下载

| 平台 | 文件 |
|------|------|
| Windows | `Pomodoro_1.0.0_x64-setup.exe` |
| macOS | `Pomodoro.app.tar.gz` |
| Linux | `pomodoro_1.0.0_amd64.deb` |

## 安装说明

**Windows**: 下载 `.exe` 运行安装即可。
**macOS**: 下载后解压，将 `.app` 拖入 Applications 文件夹。
**Linux**: 下载 `.deb` 后 `sudo dpkg -i pomodoro_1.0.0_amd64.deb`。
